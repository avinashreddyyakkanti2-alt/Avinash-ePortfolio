Overview

This project simulates a realistic e-commerce sales dataset and explores it to answer three business questions:

  1. Which product categories drive the most revenue?
  2. How does revenue trend month-over-month?
  3. Which regions have the highest average order value (AOV)?
NoteWhy synthetic data?

Working with synthetic data lets me publish the full analysis without leaking sensitive numbers from any employer or client, while still demonstrating real pandas, Plotly, and statistical reasoning skills.

The analytical workflow

Revenue calculation

Revenue is computed per order as:

\[ R_i = u_i \cdot p_i \]

where \(u_i\) is units sold and \(p_i\) is unit price. Monthly revenue is the sum across all orders in month \(m\):

\[ R_m = \sum_{i \in m} R_i \]

Generating the dataset

We generate 5,000 synthetic orders with realistic seasonality using NumPy.

Show the code 
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 5_000

categories = ["Electronics", "Apparel", "Home", "Books", "Sports"]
regions    = ["EMEA", "AMER", "APAC"]

dates = pd.date_range("2024-01-01", "2025-12-31", freq="D")
df = pd.DataFrame({
    "order_date": rng.choice(dates, n),
    "category":   rng.choice(categories, n, p=[0.30, 0.25, 0.20, 0.10, 0.15]),
    "region":     rng.choice(regions,    n, p=[0.45, 0.35, 0.20]),
    "units":      rng.integers(1, 6, n),
    "unit_price": np.round(rng.gamma(2.5, 30, n), 2),
})
df["revenue"] = (df["units"] * df["unit_price"]).round(2)
df["month"]   = df["order_date"].dt.to_period("M").dt.to_timestamp()

Question 1 — Revenue by category

Show the code 
import plotly.express as px

by_cat = (
    df.groupby("category", as_index=False)["revenue"]
      .sum()
      .sort_values("revenue", ascending=False)
)

fig = px.bar(
    by_cat, x="category", y="revenue",
    color="category",
    text_auto=".2s",
    template="plotly_white",
    title="Revenue by category",
)
fig.update_layout(showlegend=False, height=420)
fig.show()

Question 2 — Monthly revenue trend

Show the code 
monthly = df.groupby("month", as_index=False)["revenue"].sum()

fig = px.line(

## Generating the dataset

We generate 5,000 synthetic orders with realistic seasonality using NumPy.

```{python}
#| label: setup
#| fig-cap: "Data generation pipeline"
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 5_000

categories = ["Electronics", "Apparel", "Home", "Books", "Sports"]
regions    = ["EMEA", "AMER", "APAC"]

dates = pd.date_range("2024-01-01", "2025-12-31", freq="D")
df = pd.DataFrame({
    "order_date": rng.choice(dates, n),
    "category":   rng.choice(categories, n, p=[0.30, 0.25, 0.20, 0.10, 0.15]),
    "region":     rng.choice(regions,    n, p=[0.45, 0.35, 0.20]),
    "units":      rng.integers(1, 6, n),
    "unit_price": np.round(rng.gamma(2.5, 30, n), 2),
})
df["revenue"] = (df["units"] * df["unit_price"]).round(2)
df["month"]   = df["order_date"].dt.to_period("M").dt.to_timestamp()
df.head()
```

# Avinash Reddy — ePortfolio

Personal ePortfolio built with [Quarto](https://quarto.org) and deployed to GitHub Pages.
Part of the MSc Business Analytics programme at Dublin City University.

🌐 **Live site:** <https://avinashreddyyakkanti2-alt.github.io/Avinash-ePortfolio/>

## Run locally

```bash
pip install pandas numpy plotly scipy jupyter
quarto add quarto-ext/fontawesome
quarto render
quarto preview
```

## Stack

Quarto · Bootswatch Flatly + custom SCSS · Python (pandas, Plotly, SciPy) · GitHub Pages
